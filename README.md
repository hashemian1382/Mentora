# 🎓 Mentora

**پلتفرم جامع آموزشی، منتورینگ و آزمون آنلاین**

یک وبسایت شخصی/آکادمیک هوشمند برای اساتید و مشاوران آموزشی —
شامل رزومه، محتوای آموزشی، پنل منتورینگ دانش‌آموزان، بانک تست و موتور آزمون آنلاین.

## ✨ ویژگی‌ها

- 🧑‍🏫 صفحه شخصی و رزومه آکادمیک با سئوی حرفه‌ای
- 📚 مقالات آموزشی و دانلود سنتر جزوات
- 📊 پنل دانش‌آموز: برنامه‌ریزی مطالعاتی و ثبت گزارش‌کار روزانه
- 🧠 بانک تست هوشمند با دسته‌بندی مبحثی
- 📝 موتور آزمون آنلاین شخصی‌سازی‌شده با کارنامه تحلیلی
- 📈 نمودارهای تحلیل روند پیشرفت
- 🔐 احراز هویت امن با کد یکبار مصرف پیامکی

## 🛠️ استک فناوری

Next.js · TypeScript · Tailwind CSS · shadcn/ui · Prisma · PostgreSQL · Auth.js · Zod · TanStack Query

📄 برای جزئیات کامل معماری و ساختار پروژه به [`ARCHITECTURE.md`](./ARCHITECTURE.md) مراجعه کنید.

## 🚀 شروع سریع

```bash
pnpm install
cp .env.example .env
pnpm prisma migrate dev
pnpm dev
```
